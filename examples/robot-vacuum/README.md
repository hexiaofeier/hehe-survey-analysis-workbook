# 扫地机器人使用与体验：公开模拟示例

本例120份答卷完全合成，ID以SIM开头。用于展示问卷统计的交付格式与计算方法，不代表实际消费者、品牌表现或市场结论。数据版本为`synthetic-v1`。

## 文件与使用

- [responses.csv](responses.csv)：一行一份答卷；养宠和无宠家庭各60份。
- [survey-analysis.xlsx](survey-analysis.xlsx)：八张表，含使用说明、结果索引、数据分析结论、购买与使用、满意度与推荐、差异检验、数据质检、题目字典。
- [复算脚本](../../scripts/analyze_example.py)：Python 3.10+标准库，无需安装第三方库。

从仓库根目录运行`python scripts/analyze_example.py --output recomputed`，生成结果CSV和JSON。工作簿中的结果索引保存分子与分母，逐题表用公式读取结果；更换原始CSV后，先重跑脚本，再请Agent更新工作簿中的结果索引、样本量、专项结果与解读。示例脚本只处理本例字段，不是任意问卷自动识别器。

## 问卷与字段

除Q3外，选项均按下表固定顺序展示。题目只记录可用于分析的编码；空白为未答或结构性跳题，含义见路由列。

| 题号 | 题目 | 变量 | 编码与路由 |
|---|---|---|---|
| Q1 | 家中是否养宠物？ | pet | 1=养宠，0=无宠；全员 |
| Q2 | 过去一周使用扫地机器人的天数？ | frequency | 1=1—2天，2=3—4天，3=5—7天；全员 |
| Q3 | 过去一个月遇到过哪些问题？ | hair/edge/noise/wash | 毛发缠绕、边角清洁不净、噪音影响、清洗维护费时；多选，0=未选，1=选中；选项固定 |
| Q4 | 对现用机器人的总体满意度？ | satisfaction | 1=非常不满意，2=比较不满意，3=一般，4=比较满意，5=非常满意 |
| Q5 | 过去半年是否联系过售后？ | support | 1=联系过，0=没有；全员 |
| Q6 | 对最近一次售后服务的满意度？ | support_score | 与Q4同量尺；仅Q5=1时回答 |
| Q7 | 向亲友推荐现用机器人的意愿？ | recommend | 0—10分，0=完全不愿意，10=非常愿意 |
| Q8 | 体验前对新产品的购买兴趣？ | before | 1=完全没兴趣，2=较没兴趣，3=一般，4=较有兴趣，5=非常有兴趣 |
| Q9 | 体验后对新产品的购买兴趣？ | after | 与Q8同量尺；同一ID配对 |

`id`为唯一合成答卷编号。`problems_answered`是Q3作答状态，1=已作答，0=未答；已作答的全0代表没有遇到列出的四种问题，仍进入分母。未作答时四列均空。

## 分析口径

1. 总体与养宠／无宠两组均按逐题有效回答计算列百分比。Q3按有效作答人数，合计可超过100%。
2. 单题有效样本量可因缺失不同；Q6先筛选联系售后的家庭，再排除该题未答。
3. 五分量表TOP2为4—5分。Q7的NPS为推荐者（9—10分）比例减贬损者（0—6分）比例，再乘100。
4. Q8／Q9的逐题分布保留各自有效样本。差异检验只用同时回答两题的共同ID，另列配对前后TOP2，避免与单题分母混淆。
5. 唯一预设检验是体验前后TOP2的McNemar精确双侧检验；报告两种转变人数、净变化及配对差值正态近似95%区间。只有一个检验，原始p值和校正p值相同。模拟演示中的p值不用于真实市场判断。
6. 本例不加权，不做样本剔除。模拟缺失与跳题保留；不覆盖复杂抽样、价格与选择模型。

## 独立检查

`python scripts/validate_release.py`读取原始CSV独立重计分子分母，与工作簿缓存及统计结果比对，并检查引用、Skill名称、文件哈希和发布包文件范围。
