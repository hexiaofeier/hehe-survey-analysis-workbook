# 问卷数据处理与统计分析

## 技能定位

本技能检查结构化回收数据，为所有记录标记质量状态，再按用户确认的纳入范围、研究问题和问卷结构计算、解释统计结果：

`原始或已处理数据 → 全量质量标记与异常说明（如需）→ 用户确定纳入范围 → 逐题基础统计与交叉分析（如需）→ 全量标记数据及无图表 Excel 结果`

本技能负责按研究问题选择适用的基础统计与交叉分析口径，并记录选择理由；用户已指定的方法与交叉维度优先采用。

完整统计分析以“全样本整体分析＋重要人群维度的交叉分析”为基础。分析前主动确定关键维度，解释选择理由、分组定义和重点比较内容，再计算结果；全样本指用户本轮确认纳入的全部对象，逐题分母仍按显示条件和有效回答确定。用户只查某题、某组或只跑总体时，按指定范围完成。

Excel 统计工作簿不生成图表，按随包规范生成清楚、可编辑的工作簿。完整分析同时提供 Markdown 与下拉式 HTML 简报，直接使用本技能自带模板和脚本，不依赖其他报告 Skill。

## 按任务选择用法

| 用户任务 | 从哪里开始 | 完成到哪里 |
|---|---|---|
| 只清洗、验收或判断这批样本能否使用 | 读取原始数据、问卷和已有质量规则 | 全量保留并标记，交付异常说明与纳入建议，不自动跑统计 |
| 已清洗的数据需要统计分析 | 核对已有质量记录、用户纳入决定、样本与权重版本 | 沿用用户确认的范围，完成统计与解读；缺少决定时先集中确认 |
| 回收数据需要处理并分析 | 检查并标记全部记录，向用户说明异常和纳入建议 | 用户确认范围后在同一任务中接续统计，保留全量标记数据 |

用户已说明的用法直接执行；已有部分成果时从相应步骤接续。仅在缺失或冲突会改变处置、统计口径或交付范围时集中询问。

质量判断分为“明确无效、证据不足、合格”，三类均逐条留在样本表中。Agent给出异常依据和纳入建议，用户决定是否纳入；质量判断不自动转成删除、去重或统计过滤。已有用户明确确认的纳入名单或规则时直接沿用，不重复确认。

清洗与验收时读取[样本清洗与质量检查](references/sample-cleaning-and-quality.md)；只统计时核对已有质量记录，发现新问题再读取对应检查方法。访谈录音、逐字稿和观察笔记由访谈材料验收与编码能力处理；问卷设计、招募、回收和图表制作另按任务安排。

## 输入要求

优先收集以下输入：

- 已验收的可分析样本、验收结果及版本；如只有原始回收数据，先完成必要的样本质量检查并记录处置，再区分正式结果与试算；
- 问卷或题目字典；
- 变量名、题号、题型、选项文本及选项顺序；
- “选项固定/选项随机”等问卷元数据；
- 跳题逻辑、缺失值和无效值定义；
- 用户已有的分析要求、研究问题或分析方案。

清洗时补充目标人群、样本框、筛选与配额、测试/内部/补样标记，以及可得的渠道、批次、时间、设备或账号元数据和回收执行记录。缺少材料时说明受影响的检查，继续完成可判断部分；原始文件保留，转换、标记和派生均另存版本，全部提交记录保留。

如果 SAV 同时带有变量标签和值标签，应优先读取标签，不得只展示编码。

## 分析方案与确认

先将已有要求整理为简短处理或分析方案：只清洗时记录样本单位、质量规则、处置办法和输出位置；需要统计时再记录题目范围、分母、权重、交叉维度和统计指标。用户已经说清的直接执行；只有缺失或冲突会改变结果时，再集中询问对应问题，不重复要求确认整份方案。

统计方案先明确研究问题和交叉维度，再安排计算与制表；只清洗时跳过以下统计安排：

1. 本次需要支持哪些判断，哪些题目提供对应答案；
2. 主要交叉维度是什么，对应哪些题目/字段，为什么选择，如何分组，重点比较哪些题目或指标；用户已指定的维度优先沿用，其余由Agent根据研究目标、业务背景、问卷及数据主动提出；
3. 需要哪些派生指标，各自由哪些原题按什么规则计算，适用于哪些人群和分母；
4. 总体与各组输出哪些指标，哪些比较、检验或专题分析有实际用途；
5. 行表头、列表头、列百分比/行百分比及多选按人数/选择次数等口径；
6. 样本、缺失值、跳题、无效值、权重和配额如何处理；
7. 工作表如何拆分、题目如何排序，固定/随机及特殊选项如何呈现；
8. 输出文件名、目录和本次交付范围。

需要统计时，读取[统计口径与方法选择](references/statistical-methods.md)：第0节用于选择交叉维度、核对统计对象和定义派生指标，后续章节按回答人群及独立／配对关系确定分母、权重、指标和检验。使用[分析方案记录模板](references/analysis-plan-template.md)记录已定口径及待确认项，不另造交付文件；材料足以判断时直接执行，仅会改变研究含义且无法确定的分组边界或指标口径集中询问。

基础跑数可复用 [基础统计脚本说明](references/basic-statistics.md) 中的随包脚本，按实际字段配置题目、显示条件、分组和权重；配置支持范围之外的专项继续按对应方法使用项目脚本，不以基础脚本的题型限制本技能能力。

未指定的分析方法按研究问题、题型和样本条件选择，并说明原因；对会改变结论且无法从材料判定的冲突标注 `【待核实】`，请用户决定。局部题目受阻时，继续完成口径明确的其他部分。

## 执行流程

### 1. 样本检查、清洗与处置

已有验收或清洗成果时，核对样本、问卷、字段、规则和权重版本、用户纳入决定，以及各题组/分组的可用范围；有交接 ID 时一并核对。沿用用户已确认的纳入、不纳入和权重决定，不因进入统计阶段重新判断。只有原始数据或原有记录不足时，按[样本清洗与质量检查](references/sample-cleaning-and-quality.md)完成以下操作：

1. 登记原始文件、记录数、回收范围和版本，区分受访者、答卷、提交记录、渠道、批次及重复测量单位；识别数据表、变量标签和值标签，排除 Excel 临时文件。
2. 建立质量规则，写明字段、判断方法、阈值依据和版本；为每条记录标记“明确无效、证据不足、合格”之一，正常记录也明确标记。
3. 检查目标人群与配额、测试/重复/疑似代答、缺失和跳题、编码与取值、时长与机械作答、开放题、样本内一致性、跨答卷异常相似、渠道/批次/版本以及覆盖与非响应。按规则整理数据和标记异常，保留原值与转换依据。
4. 在全量记录中写入质量判断、异常标记与说明、证据、Agent纳入建议及单独的用户纳入决定。异常记录可有多个标记，但汇总人数按记录或受访者单位去重计数。明确无效和证据不足的记录提供异常样本说明；合格记录同样保留，均不直接删除。
5. 向用户说明不同纳入选择对人数、配额和结果的影响；已确认范围时比较纳入前后结构。需要判断影响时核对少量关键指标，不扩成完整统计。明确总体、分组、题组的分析条件、加权条件及补样等办法。
6. 只清洗时交付全量标记表、异常说明和待决定事项。需要统计且缺少用户纳入决定时，先集中请用户确认；确认后按选择接续，未纳入的记录仍保留在全量表中。用户要求不同纳入方案试算时分开标明，不能把Agent建议当作已确认范围。

分析中发现新问题时，在本任务中更新处理记录与样本版本，并仅重跑受影响结果；原始数据和旧版成果保留。因问卷版本、跳题或渠道造成的问题，先判断受影响题组或批次，不直接把全部异常归为无效答卷。

### 2. 题目识别

按问卷或题目字典识别：

- 单选题；
- 多选题；
- 矩阵单选题；
- 矩阵多选题；
- 五分制或其他量表题；
- 排序题；
- 开放题；
- 派生变量；
- 漏斗、Kano 等专项题组。

题型和选项顺序不能只依赖样本结果表。识别优先级为：

1. 用户明确指定的题型和顺序；
2. 原问卷中的题型、选项文本及“固定/随机”标记；
3. 问卷逻辑表、题目字典或平台导出的元数据；
4. 题目和选项本身可明确识别的语义顺序；
5. 样本结果中的原始列顺序。

如果回收数据未携带“固定/随机”标记，应同步读取原问卷。原问卷也缺失时，可根据明确语义识别顺序，并将推断写入分析方案。问卷标记与题目语义明显冲突时，标记 `【待核实】`，请用户决定。

无法可靠判断题型或选项顺序时，暂停该题并询问用户，其余已明确题目继续分析。

### 3. Sheet 组织

- 统计工作簿第1张为“使用说明”，第2张为“分析方案”；结果索引仅保存在后台复核文件，不加入交付 Excel；
- 按原问卷模块或用户指定模块拆分工作表；
- 模块内严格按原问卷题号顺序排列；
- 用户画像可单独成 sheet；
- 其他模块可按 A、B、C、D 等问卷章节拆分；
- 使用说明、数据质检、专项分析和开放题可独立成 sheet；
- 不因结果大小改变题目之间的先后顺序。

### 4. 题内选项排序

- 有序量表、时间顺序、年龄区间、收入区间、使用频率、使用时长、城市级别、教育程度、漏斗阶段、流程顺序、Likert 量表，以及其他具有天然等级或先后关系的题目：保持原问卷或确认后的逻辑顺序；
- 问卷明确标记为“选项固定”的题目：一律保持原问卷选项顺序，不按结果大小重新排序；
- 问卷标记为“选项随机”的题目：按总体占比从高到低排列；
- 如果随机题实际包含明确的等级、时间或流程关系，不直接降序，先在分析方案中标记 `【待核实】`，由用户确认按逻辑顺序还是总体占比排序；
- 多系列交叉表仍以总体占比作为共同排序键；
- “其他”“以上均无”“不知道”等特殊项是否置底，以确认方案为准；
- 不得按某一个品牌列或某一个细分人群列单独排序。

### 5. 基础结果

完整统计任务保留范围内全部题目的总体结果，按原问卷模块和题序呈现；重点交叉和专题解读不替代逐题基础表。零频选项按字典保留，暂不能计算的题保留位置并注明具体缺项。

按已确定的分析口径输出。常见结构包括：

- 单选题：选项、总体比例、交叉组比例、总计、样本量；
- 多选题：选项、总体选择率、交叉组选择率、总计、样本量；其中“总计”为各选项选择率之和，可超过 100%；
- 矩阵单选题：各行项目的选项分布、TOP2/均值等确认指标，以及总体和交叉组 Base；
- 矩阵多选题：各行项目下每个选项的选择率，按总体及交叉组分别计算，并统一输出各项目“样本量”；
- 量表题：各档比例、TOP2、总计%、均值、样本量；
- 排序题：各名次比例、平均名次或综合得分；
- 开放题：原文、编码结果或词频，按任务要求输出。

选择与研究问题有关的指标并记入分析方案，不为凑表加入无关指标。

按[统计口径与方法选择](references/statistical-methods.md)落实逐题有效样本、未选与未答、量表方向和排序题口径。加权结果仍保留实际“样本量”，另列计算使用的“权重和”；后台结果索引中的“有效Base”记录实际计算分母。

### 6. 交叉分析

- 完整分析将已确定的主要维度贯穿各模块中可分析且口径相容的画像、行为、需求和评价题，在逐题总体旁呈现分组结果；专题页用于进一步追查。先确定维度、分组和覆盖范围，再检查差异，不只挑差异大的题；覆盖安排见统计口径参考第0节。用户只查局部时沿用其范围，指定全部交叉组合时按其要求完成。
- 严格执行确认后的行表头、列表头和百分比口径；
- 常规交叉表默认使用列百分比：`总计`列以该题全部有效样本为分母，各交叉组列分别以该组有效样本为分母；
- `总计`是总体结果列，不是额外的交叉组选项；它与各交叉组列并列展示，但分母不同；
- 对单选题，分母大于0时每个结果列的选项比例应分别合计为 100%；底部“总计”行显示 100%，“样本量”行显示总体及各组实际有效人数；
- 对多选题和矩阵多选题，各列选择率之和允许超过 100%，默认按该列有效答题人数计算；加权时对同一有效人群使用权重和，用户指定按选择次数计算时另行标明；
- 所有列均显示有效 Base；
- 不同题目因跳题产生不同 Base 时必须分别计算；
- 配额变量不得解释为自然市场份额；
- 小样本列保留结果时，应同步标注样本量和解释边界。

### 7. 专项分析

在用户要求，或研究问题确需且数据条件支持时执行：

- 均值显著性检验；
- 两两检验及多重比较校正；
- Kano 或 Kano 变种分析；
- 漏斗分析；
- 品牌迁移与留存；
- 题目合并与互补样本汇总；
- 纵向对比；
- 其他定制统计模型。

每项专项分析必须写明变量、样本范围、计算方法和解释限制。

检验选择与差异表达见[统计口径与方法选择](references/statistical-methods.md)；Kano、漏斗、迁移、合并及纵向分析见[专项分析计算参考](references/special-analysis-methods.md)。后者也提供驱动因素、分群、量表和价格等按需方法的输入与交付要求。

### 8. 格式与输出

- Excel 统计工作簿不生成图表；
- 默认使用清楚、统一、可编辑的表格格式；
- 所有可见文字使用微软雅黑；
- 工作表隐藏网格线；
- 结果表默认深蓝白字表头，正文及汇总行统一白底、细灰色单元格边框；题目与选项左对齐，数值右对齐，总计与样本量加粗，具体色值见输出规范；
- 题目块之间使用清晰分隔；
- 题目仅在题目块首行显示，后续行留空，不合并单元格，以保留机器可读性；
- 冻结表头和必要的题目列；
- 保留原始数据文件，输出带日期或版本号的新文件。

详细输出结构见 [工作簿输出规范](references/workbook-output-spec.md)。另存全量标记数据，原记录数和原字段值保留；质量摘要、异常说明、规则、用户纳入决定、结构比较、分析条件和权重记录可集中在同一工作簿。用户确认后可另导出纳入分析的数据或使用明确的筛选标记，全量表继续保留。只清洗时不生成统计结果表。

有统计结果时，在过程文件中保存独立 JSONL 或 CSV 结果索引，供复核和图表库等下游使用，不加入交付 Excel：`结果ID｜题号/变量｜指标｜总体/分组｜分子｜有效Base｜权重版本｜百分比口径｜结果位置｜来源样本版本｜限制`。工作簿目录和结论直接链接实际结果表，不经过索引。

完整分析先概括总体行为、需求及购买或使用条件，再解释重点人群差异；对有业务价值且现有字段能够追查的差异，实际进行进一步分层或跨题比较，形成有依据的建议取舍。在“数据分析结论”中按研究问题汇集结果并链接对应表格，具体步骤见统计口径参考第5节；用户只要求局部解读时按对应范围展开。单纯跑数任务在题目块附近保留必要口径说明，不扩成完整研究报告。

完整分析默认另交同内容的 Markdown 与 HTML 简报，概括主要发现、人群差异和业务含义，并指向统计工作簿中的证据；不把全部逐题明细搬入网页。制作时读取 [HTML简报交付](references/html-brief.md)，用随包脚本生成带左侧目录的下拉阅读版。只清洗、仅跑数或局部查题不自动扩成简报；用户要求简报时按本次范围制作。

## 质量闸门

所有用法先检查原始文件未变、全量记录数未减少、三类质量状态覆盖全部记录、正常与异常标记可追溯、异常人数不重复计数，且质量判断和用户纳入决定分列。只清洗时核对转换、标记、异常说明和待决定事项；需要统计时再检查：

- 有效样本量与本次纳入规则、当前样本版本及逐题有效回答范围一致；
- 统计筛选与用户已确认的纳入决定一致，未因质量标签自动过滤记录；
- 有交叉或派生指标时，核对维度的研究理由、实际字段和分组定义，重点比较及派生指标能追溯到方案；完整分析逐模块核对主要维度的实际覆盖，未交叉题目有具体原因；
- 完整解读包含总体发现；重点差异已利用相关现有字段追查，建议说明对象、依据和优先理由；有类型核验或重分类的派生结果能追溯到后台对象对应表；
- 本次范围内逐题结果完整，完整分析保留全部题目总体结果；有交叉或结论时，比较对象和分母可核对，结论能点击定位到对应明细；
- 各单选题比例在有效口径下合计为 100%；
- 多选题比例允许超过 100%，且分母口径已写明；
- 所有题目的有效回答人数统一标为“样本量”；
- 多选题与矩阵多选题均有“总计”行，且等于各选项选择率之和；
- 量表分布、TOP2、均值和样本量可由明细复算；
- 交叉表总计列与总体结果一致；
- 跳题题目的 Base 正确；
- 固定题保持原顺序，随机题按总体占比降序；
- 显著性结论与检验结果一致；
- 合并题不重不漏；
- 工作簿无图表对象；
- 数据、公式和统计结论未因格式处理被改变。
- 后台结果索引、工作簿数值与样本验收版本一致；有新样本处置时仅重跑受影响结果。
- 交付 Excel 不含结果索引工作表；前两张依次为使用说明、分析方案，目录及结论链接均直接指向存在的工作表或单元格。
- 交付 HTML 简报时，逐项核对其数字、分母与工作簿一致，检查目录跳转、附件链接、桌面及窄屏阅读；具体检查见 HTML 简报参考。

统计执行时分别复核计算、数据处理、单表和跨表一致性；每种实际使用的题型与算法选已知答案的小例子复算，重点覆盖跳题、多选、权重和配对关系，核对后再应用于全量数据。

## 交付说明

向用户说明：

- 输入数据文件；
- 已确认的分析方案；
- 输出文件路径；
- sheet 数量与结构；
- 有效样本量；
- 已执行的专项分析；
- 数据异常、样本限制和 `【待核实】` 项；
- 随结果提供可重复运行的计算脚本、所需依赖与运行方式，并说明更新数据后如何重算工作簿。

只清洗时说明全量记录数、独立受访者数、三类质量判断人数、异常及依据、纳入建议和用户待决定事项，交付全量标记数据与异常说明。需要统计时沿用用户确认的选择，交付工作簿并说明纳入/未纳入人数。处理脚本与统计脚本可合为一份，检查标记阶段不删行，统计筛选读取用户决定或已确认规则。
