# 用户调研基础分析工作簿

## 技能定位

本技能负责用户调研制表流程的第一阶段：

`已验收样本或原始回收数据 → 样本状态与分析口径确认 → 逐题基础统计与交叉分析 → 无图表 Excel 分析报告`

本技能负责按研究问题选择适用的基础统计与交叉分析口径，并记录选择理由；用户已指定的方法与交叉维度优先采用。

本技能不生成图表。具备 `iresearch-excel-format` 且用户需要该样式时可调用；否则自行生成清楚、可编辑的工作簿。

## 输入要求

优先收集以下输入：

- 已验收的可分析样本、验收结果及版本；如只有原始回收数据，先完成必要的样本质量检查并记录处置，再区分正式结果与试算；
- 问卷或题目字典；
- 变量名、题号、题型、选项文本及选项顺序；
- “选项固定/选项随机”等问卷元数据；
- 跳题逻辑、缺失值和无效值定义；
- 用户已有的分析要求、研究问题或分析方案。

如果 SAV 同时带有变量标签和值标签，应优先读取标签，不得只展示编码。

## 分析方案与确认

先将已有要求整理为简短分析方案，记录样本版本、题目范围、分母、权重、交叉维度、统计指标和输出位置。用户已经说清的直接执行；只有缺失或冲突会改变结果时，再集中询问对应问题，不重复要求确认整份方案。

方案按任务检查：

1. 工作表如何拆分，题目按什么顺序排列；
2. 哪些变量作为主要交叉分析的列表头；
3. 哪些题与哪些变量交叉，行表头和列表头分别是什么；
4. 每类题输出哪些指标；
5. 交叉表输出列百分比、行百分比还是其他口径；
6. 多选题使用答题人数还是选择次数作为分母；
7. 哪些题需要均值检验、两两检验、Kano、漏斗或其他专项分析；
8. 缺失值、跳题、无效值、权重和配额如何处理；
9. 特殊选项如“其他”“以上均无”“不知道”是否固定置底；
10. 输出文件名和目标目录。

可用 [分析方案记录模板](references/analysis-plan-template.md)记录已定口径与待确认项。

按研究问题选择方法时，读取[统计口径与方法选择](references/statistical-methods.md)：先明确比较对象、回答人群和独立／配对关系，再确定分母、权重、指标和检验。

未指定的分析方法按研究问题、题型和样本条件选择，并说明原因；对会改变结论且无法从材料判定的冲突标注 `【待核实】`，请用户决定。局部题目受阻时，继续完成口径明确的其他部分。

## 执行流程

### 1. 数据检查

- 已有 `survey-fieldwork-qc` 验收包时，核对交接 ID、样本/问卷/字段/权重版本与分析许可矩阵；沿用其纳入、剔除和权重决定，不在制表中静默重判。
- 只有原始数据时，先确认目标人群和有效样本定义，检查下列问题并记录处置；不能可靠确定纳入或权重时，只交付标明样本状态的试算，不把它写成正式结论。
- 识别数据表、变量标签和值标签；
- 排除 Excel 临时文件；
- 检查重复样本、空白样本、异常编码和越界值；
- 核对有效样本量；
- 检查跳题逻辑和互斥题关系；
- 输出数据检查结果；发现会改变已验收样本范围的新问题时，记录并回到样本验收形成新版本，不静默修复原始数据。

### 2. 题目识别

按问卷或题目字典识别：

- 单选题；
- 多选题；
- 矩阵单选题；
- 矩阵多选题；
- 五分制或其他量表题；
- 排序题；
- 开放题；
- 派生变量；
- 漏斗、Kano 等专项题组。

题型和选项顺序不能只依赖样本结果表。识别优先级为：

1. 用户明确指定的题型和顺序；
2. 原问卷中的题型、选项文本及“固定/随机”标记；
3. 问卷逻辑表、题目字典或平台导出的元数据；
4. 题目和选项本身可明确识别的语义顺序；
5. 样本结果中的原始列顺序。

如果回收数据未携带“固定/随机”标记，应同步读取原问卷。原问卷也缺失时，可根据明确语义识别顺序，并将推断写入分析方案。问卷标记与题目语义明显冲突时，标记 `【待核实】`，请用户决定。

无法可靠判断题型或选项顺序时，暂停该题并询问用户，其余已明确题目继续分析。

### 3. Sheet 组织

- 按原问卷模块或用户指定模块拆分工作表；
- 模块内严格按原问卷题号顺序排列；
- 用户画像可单独成 sheet；
- 其他模块可按 A、B、C、D 等问卷章节拆分；
- 使用说明、数据质检、专项分析和开放题可独立成 sheet；
- 不因结果大小改变题目之间的先后顺序。

### 4. 题内选项排序

- 有序量表、时间顺序、年龄区间、收入区间、使用频率、使用时长、城市级别、教育程度、漏斗阶段、流程顺序、Likert 量表，以及其他具有天然等级或先后关系的题目：保持原问卷或确认后的逻辑顺序；
- 问卷明确标记为“选项固定”的题目：一律保持原问卷选项顺序，不按结果大小重新排序；
- 问卷标记为“选项随机”的题目：按总体占比从高到低排列；
- 如果随机题实际包含明确的等级、时间或流程关系，不直接降序，先在分析方案中标记 `【待核实】`，由用户确认按逻辑顺序还是总体占比排序；
- 多系列交叉表仍以总体占比作为共同排序键；
- “其他”“以上均无”“不知道”等特殊项是否置底，以确认方案为准；
- 不得按某一个品牌列或某一个细分人群列单独排序。

### 5. 基础结果

按已确定的分析口径输出。常见结构包括：

- 单选题：选项、总体比例、交叉组比例、总计、样本量；
- 多选题：选项、总体选择率、交叉组选择率、总计、样本量；其中“总计”为各选项选择率之和，可超过 100%；
- 矩阵单选题：各行项目的选项分布、TOP2/均值等确认指标，以及总体和交叉组 Base；
- 矩阵多选题：各行项目下每个选项的选择率，按总体及交叉组分别计算，并统一输出各项目“样本量”；
- 量表题：各档比例、TOP2、总计%、均值、样本量；
- 排序题：各名次比例、平均名次或综合得分；
- 开放题：原文、编码结果或词频，按任务要求输出。

选择与研究问题有关的指标并记入分析方案，不为凑表加入无关指标。

按[统计口径与方法选择](references/statistical-methods.md)落实逐题有效样本、未选与未答、量表方向和排序题口径。加权结果仍保留实际“样本量”，另列计算使用的“权重和”；结果索引中的“有效Base”记录实际计算分母。

### 6. 交叉分析

- 严格执行确认后的行表头、列表头和百分比口径；
- 常规交叉表默认使用列百分比：`总计`列以该题全部有效样本为分母，各交叉组列分别以该组有效样本为分母；
- `总计`是总体结果列，不是额外的交叉组选项；它与各交叉组列并列展示，但分母不同；
- 对单选题，分母大于0时每个结果列的选项比例应分别合计为 100%；底部“总计”行显示 100%，“样本量”行显示总体及各组实际有效人数；
- 对多选题和矩阵多选题，各列选择率之和允许超过 100%，默认按该列有效答题人数计算；加权时对同一有效人群使用权重和，用户指定按选择次数计算时另行标明；
- 所有列均显示有效 Base；
- 不同题目因跳题产生不同 Base 时必须分别计算；
- 配额变量不得解释为自然市场份额；
- 小样本列保留结果时，应同步标注样本量和解释边界。

### 7. 专项分析

在用户要求，或研究问题确需且数据条件支持时执行：

- 均值显著性检验；
- 两两检验及多重比较校正；
- Kano 或 Kano 变种分析；
- 漏斗分析；
- 品牌迁移与留存；
- 题目合并与互补样本汇总；
- 纵向对比；
- 其他定制统计模型。

每项专项分析必须写明变量、样本范围、计算方法和解释限制。

检验选择与差异表达见[统计口径与方法选择](references/statistical-methods.md)；Kano、漏斗、迁移、合并及纵向分析见[专项分析计算参考](references/special-analysis-methods.md)。后者也提供驱动因素、分群、量表和价格等按需方法的输入与交付要求。

### 8. 格式与输出

- 不生成任何图表；
- 默认使用清楚、统一、可编辑的表格格式；用户指定 iResearch 样式且 `iresearch-excel-format` 可用时再调用；
- 所有可见文字使用微软雅黑；
- 工作表隐藏网格线；
- 表头、正文、数字格式、边框、行高和字色保持统一；
- 题目块之间使用清晰分隔；
- 题目仅在题目块首行显示，后续行留空，不合并单元格，以保留机器可读性；
- 冻结表头和必要的题目列；
- 保留原始数据文件，输出带日期或版本号的新文件。

详细输出结构见 [工作簿输出规范](references/workbook-output-spec.md)。另给图表库等下游留下结果索引：`结果ID｜题号/变量｜指标｜总体/分组｜分子｜有效Base｜权重版本｜百分比口径｜结果位置｜来源样本版本｜限制`。

完整分析或用户要求解读时，在“数据分析结论”中按研究问题解释主要结果、人群差异及实际含义，并链接对应表格；单纯跑数任务在题目块附近保留必要口径说明。

## 质量闸门

交付前必须检查：

- 有效样本量与源数据一致；
- 各单选题比例在有效口径下合计为 100%；
- 多选题比例允许超过 100%，且分母口径已写明；
- 所有题目的有效回答人数统一标为“样本量”；
- 多选题与矩阵多选题均有“总计”行，且等于各选项选择率之和；
- 量表分布、TOP2、均值和样本量可由明细复算；
- 交叉表总计列与总体结果一致；
- 跳题题目的 Base 正确；
- 固定题保持原顺序，随机题按总体占比降序；
- 显著性结论与检验结果一致；
- 合并题不重不漏；
- 工作簿无图表对象；
- 数据、公式和统计结论未因格式处理被改变。
- 结果索引、工作簿数值与样本验收版本一致；有新样本处置时仅重跑受影响结果。

执行时分别复核计算、数据处理、单表和跨表一致性；每种实际使用的题型与算法选已知答案的小例子复算，重点覆盖跳题、多选、权重和配对关系，核对后再应用于全量数据。

## 交付说明

向用户说明：

- 输入数据文件；
- 已确认的分析方案；
- 输出文件路径；
- sheet 数量与结构；
- 有效样本量；
- 已执行的专项分析；
- 数据异常、样本限制和 `【待核实】` 项；
- 随结果提供可重复运行的计算脚本、所需依赖与运行方式，并说明更新数据后如何重算工作簿。
