# 样本检查、全量标记与纳入确认

用于只清洗或清洗后统计；已有清洗成果时只核对其版本和可用范围，发现新异常再补查相关项目。

## 0. 读取与整理数据

读取目标人群、样本框、筛选条件、配额和有效样本定义；问卷最终版、版本变更、题目—变量字典、选项编码及跳题/显示逻辑；原始回收数据及可得的渠道、批次、时间、设备/账号元数据；测试、内部、补样、正式样本标记和执行异常记录。

登记原始文件、数据集 ID、问卷/字段/规则版本、记录数、回收范围与文件校验信息。区分受访者、答卷、提交记录和回收批次，同人多次提交不能直接算成多个独立样本；追踪或多任务数据保留对应波次/任务。

按字典核对字段名、类型、标签、选项编码、日期和金额单位及缺失值标记。需要映射或转换时，保留原值、转换规则与转换后字段。区分未展示、展示未答、有效未选和实际选择，多选全空或全0先按平台编码和路由判定，不能直接补成未选。缺少材料时列出受影响的检查，先完成可以判断的部分。

## 1. 使用原则

- 保留原始数据及全部提交记录，在另存的全量表中增加质量判断、异常说明和纳入决定；正常、明确无效、证据不足的记录均不直接删除。
- 项目设计和执行记录优先于通用经验阈值；无项目阈值时只能把启发式条件用于筛查。
- 区分受访者、答卷、提交记录、渠道和批次，明确每张表的分析单位与去重单位。
- 单个弱信号只触发复核；多个相互独立的信号共同出现，才提高风险等级。
- 对系统性版本、跳题或渠道问题，先处理问题影响范围，不把责任全部推给受访者。
- 质量判断、Agent建议与用户纳入决定分别记录。用户可逐条或按确认的规则决定；未确认时不自动过滤样本。异常汇总按记录或受访者单位去重计数，多个异常标记仍保留。

## 2. 质量规则表

每次项目先建立：

`规则ID｜质量维度｜适用记录/字段｜判断方法｜阈值或条件｜阈值来源｜风险等级｜质量判断｜纳入建议｜用户确认的纳入规则（如有）｜版本`

阈值来源可写：研究设计、客户确认、供应商规则、历史项目校准、问卷预试或本轮探索性筛查。探索性筛查不得冒充预先确定的有效样本标准。

## 3. 检查维度

| 维度 | 重点检查 | 判断要点 |
|---|---|---|
| 身份与纳入 | 目标人群、筛选题、配额身份、测试/内部样本、受访者与提交记录关系 | 明确违反筛选条件标记“明确无效”；身份缺证标记“证据不足”，均保留供用户决定 |
| 重复与代答 | 用户、账号、联系方式、设备、IP、邀请链接、答案与时间组合 | 依法且按项目可得字段判断；共享网络或设备不能单独证明重复 |
| 完整性与跳题 | 空白、题目缺失、必答漏答、跳题/显示路径、问卷中断 | 区分系统缺失、设计缺失和受访者非响应 |
| 时长与节奏 | 总时长、页面停留、异常快慢、批量相似节奏 | 结合问卷长度、设备、熟悉度和预试分布，不使用万能秒数 |
| 机械作答 | 直线、循环、固定位置、矩阵低方差、注意力题 | 某些真实态度可能高度一致；单一模式先标记 |
| 样本内一致性 | 相关题、重复测量题、反向题、筛选—行为—态度上下游关系 | 先确认时间范围、对象和场景一致；真实矛盾或态度复杂不等于随机 |
| 样本间异常相似 | 答案向量、路径、时长、时间邻近、开放题和元数据的共同重合 | 建立疑似同源样本簇；不能仅凭答案相似判无效 |
| 开放题质量 | 空话、乱码、复制、模板、与题目无关、跨样本近似文本 | 短回答不必然无效；结合题目所需信息量判断 |
| 编码与取值 | 越界、类型错误、单位异常、不可能值、日期和金额错误 | 区分导出错误、字段映射错误和真实极端值 |
| 渠道与批次 | 渠道结构、批次突变、集中提交、供应商差异、设备分布 | 渠道差异可能是真实构成差异，需结合招募机制判断 |
| 版本与字段 | 问卷版本、题目/选项变更、字段重命名、编码重用 | 无法建立映射的版本不得直接合并 |
| 缺失与非响应 | 逐题缺失、分群缺失、关键题组无响应、退出位置 | 报告缺失机制和受影响人群，不只报告整体缺失率 |
| 配额与覆盖 | 总量、各层配额、关键人群缺口、样本框覆盖、选择机制 | 配额达成不等于总体代表性；覆盖缺失不能靠加权自动修复 |

## 4. 样本内一致性检查

### 4.1 先建立题目关系表

`关系ID｜题目A｜题目B/题组｜关系类型｜预期方向或约束｜允许例外｜适用人群｜版本`

关系类型包括：

- 明确逻辑约束，例如“从未购买”与“最近购买次数大于零”；
- 同一概念的重复测量；
- 正向题与反向题；
- 筛选、认知、使用、态度和满意度之间的上下游关系；
- 量表内部的预期同向或反向关系。

### 4.2 判断顺序

1. 先确认两题对象、时间范围、场景和量尺是否一致；
2. 判断是明确逻辑不可能、弱不一致，还是可以合理共存的复杂态度；
3. 结合时长、机械作答、开放题等其他信号判断；
4. 记录矛盾题对和解释，不用一个综合分数掩盖具体证据。

单份答卷不能仅凭“相关性低”判无效。题组在全体样本中的相关性或信度异常，可能指向量表设计、翻译、编码或多维结构问题，应登记为问卷/量表风险并退回研究设计复核。

## 5. 样本间异常相似性检查

### 5.1 比较特征

按题型和字段可得性选择：

- 单选、量表和矩阵答案的逐题重合；
- 多选集合的相似性；
- 跳题、缺失、错误答案和页面路径；
- 总时长、页面停留和提交时间间隔；
- 开放题原文、轻微改写和模板结构；
- 渠道、批次及依法可用的账号/设备等元数据。

不得把不同题型粗暴拼成一个没有解释的统一相似度。报告采用了哪些字段、如何处理缺失和权重。

### 5.2 建立疑似同源样本簇

`样本簇ID｜涉及记录/样本ID｜答案重合范围｜主要不同项｜路径相似｜时间区间/间隔｜时长相似｜开放题相似｜共同元数据｜独立异常信号数｜纳入建议｜用户纳入决定`

高答案重合与相邻时间可以触发复核；若再叠加相似路径、时长、开放题或元数据，风险提高。相似人群、短问卷、共同事件和相同招募场景也可能产生真实相似，必须保留替代解释。

样本簇内逐条保留标记和建议。可比较“全量纳入/按建议排除重复”的人数及结果影响，方案标为待确认或试算，由用户选择纳入范围；确定重复的记录也留在全量表中。

## 6. 全量标记与用户决定

每条提交记录保留稳定的记录ID，另列受访者ID；同人多次提交仍逐条保留。全部记录标记以下一种质量判断：

| 质量判断 | 含义 |
|---|---|
| 明确无效 | 有充分证据确认违反样本条件或质量规则，说明具体原因，建议是否纳入由Agent给出 |
| 证据不足 | 有异常信号但无法确认无效，列出依据及需要复核的信息 |
| 合格 | 在已完成的检查范围内未发现异常，明确写“无异常”，同样保留记录 |

全量表至少增加：

`记录ID｜受访者ID｜质量判断｜异常标记（正常写无异常）｜异常说明｜涉及规则/证据定位｜影响字段/题组｜Agent纳入建议｜用户纳入决定｜决定依据/来源｜版本`

异常样本说明可另列异常记录，包含证据组合、其他可能解释、纳入与不纳入对人数/配额/结论的影响及建议；正常记录仍在全量表中。用户纳入决定使用“纳入、不纳入、待决定”，无已确认名单或规则时填“待决定”，不从质量标签自动赋值。

用户可按类别、异常规则、样本簇或逐条确认，记录决定者、依据与时间。已有用户明确确认的名单或规则直接沿用，不重复询问；用户选择纳入异常答卷时保留原质量判断与异常说明。答卷纳入不等于每题每个值均有效，逐题仍按确认的显示条件、编码及有效回答口径计算。

## 7. 质量影响与分析许可

分别判断总体、分组、题组和渠道能否描述、比较、推断或外推，记录Base过小、覆盖不足及选择机制不清的影响；据此提出补样、合并分组、限定总体、敏感性分析或加权。只清洗时，关键指标比较服务于判断处置影响，不自动扩成完整统计分析。

### 7.1 全量与纳入范围的结构对比

至少比较总体、关键配额、渠道和核心分析分组：

`分组｜全量n/占比｜三类质量人数｜用户已确认纳入n｜未纳入n｜待决定n｜差异｜可能原因｜分析影响`

必要时比较不同纳入方案的结构和关键指标，区分已确认范围与待确认试算；全量数据行数保持不变。

### 7.2 分析许可矩阵

`许可ID｜分析对象/题组｜样本版本｜适用人群/渠道｜有效Base｜未加权/加权｜允许分析｜条件允许｜禁止分析｜主要偏差｜解释上限｜补救条件`

许可状态必须具体到总体、分组、题组或比较任务。总体放行不能覆盖局部禁用项。

## 8. 加权记录

`权重版本｜目标总体/来源｜权重变量｜方法｜未加权Base｜加权Base｜权重范围｜极端权重处理｜有效样本量影响｜允许用途｜禁止用途`

- 无可靠目标分布、关键人群完全缺失或单元格过小时，不建议加权。
- 权重形成前先确认用户的纳入范围及适用对象；权重不用于掩盖欺诈或执行错误。
- 下游结果须标记使用的权重版本，同时保留未加权样本量。

## 9. 质量结果与统计接续

先交付全量标记和异常说明，再确定统计所用的用户纳入决定。有已确认的名单或规则时直接接续；没有时集中请用户选择，不能将Agent的质量判断或建议当作用户决定。题组存在字段、版本或计算条件缺口时，说明受影响范围，其他已确认部分继续。

质量摘要至少包含：

`总回收｜独立受访者数｜明确无效/证据不足/合格人数｜主要异常及依据｜用户已纳入/未纳入/待决定人数｜配额与覆盖偏差｜字段/问卷版本｜权重状态｜分析条件`

默认交付样本检查工作簿（`.xlsx`）、可复跑脚本及运行说明，输入格式不改变这一默认交付方式；具体文件形式、标签字典和统计接续方式见[工作簿输出规范](workbook-output-spec.md)第0节。

样本检查工作簿保留以下八类内容：原始数据快照说明、全量标记样本表、质量标记与用户纳入决定明细、规则与阈值依据及版本、质量摘要与纳入范围结构对比、各项分析条件、权重状态与适用边界、文件/字段版本清单。全量表保留全部原始记录及字段值；其余相关内容可合页。用户确认后可另导出纳入数据或在统计脚本中读取决定标记，全量表继续保留。

在本任务中复用这些记录进入统计；向其他人员或工具移交时也可使用以下字段：

`交接ID｜原始数据快照/校验值｜全量标记文件｜用户纳入决定及来源｜样本版本｜问卷版本｜字段字典版本｜规则版本｜全量记录数｜独立受访者数｜纳入/未纳入/待决定数｜权重变量/版本｜各项分析条件｜已知限制｜待解决项｜生成时间`

统计前核对用户纳入决定、样本、问卷、字段、规则及权重版本；已有交接 ID 时一并核对。记录不一致或不足时，补查对应范围并更新记录；相关问题未解决前，限定该部分的统计用途，其余明确可用部分继续。已确认的纳入、不纳入和权重决定沿用；需要调整纳入范围时提交新异常及影响，请用户决定并记录新版本。

## 10. 版本与回流

- 每次人工决定、规则改变、补样、字段修复或权重改变均生成新验收版本；旧版保留。
- 记录变更原因、受影响样本/字段、有效样本变化和需重跑的分析结果。
- 分析中发现新异常时，在同一任务内登记、复核和更新处理结果；按新版本的可用范围继续，仅重跑受影响结果。
