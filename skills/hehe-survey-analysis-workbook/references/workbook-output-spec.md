# 基础分析工作簿输出规范

## 1. 通用结构

- 第一张 sheet 为“使用说明”；
- 第二张为“结果索引”，记录题号、指标、样本版本、Base、权重、口径和结果位置；需要时另设“数据分析结论”；
- 中间 sheets 按问卷模块和原题号顺序排列；
- 末尾放数据质检、专项分析、开放题原文或合并检查；
- 工作簿不包含图表。

## 2. 基础表结构

常规交叉表使用宽表：

`题目 / 选项 / 总计 / 交叉组1 / 交叉组2 / …`

- 题目只在题目块第一行显示；
- 题目块之间使用上边框或空行区分；
- `总计`列表示全部有效样本的总体结果，各交叉组列表示各组内部结果；
- 常规单选交叉默认输出列百分比，每一结果列分别合计为 100%；
- 题目块底部增加“总计”行和“样本量”行；
- 单选题分母大于0时，“总计”行在总体列和各交叉组列均显示 100%；
- “样本量”行分别显示总体及各交叉组实际有效人数；
- 所有题目的有效回答人数统一命名为“样本量”，不得混用“答题人数”“Base”等其他行名；
- 多选题和矩阵多选题也必须增加“总计”行；该行等于本列所有多选项选择率之和，因此允许超过 100%；
- 多选题和矩阵多选题的“样本量”仍为回答该题的人数，不是选择次数；
- 题目块内部顺序遵守题目排序规则。
- 原问卷标记为“选项固定”的题目，严格按原问卷选项顺序呈现。

加权表以权重和计算比例与均值，“样本量”行仍显示实际有效人数，另增“权重和”行；需要评价权重离散程度时附“Kish有效样本量（权重近似）”。原始频数为整数，加权频数可保留小数，二者使用不同列名。分母为0的结果显示“—”，真实0次选择且分母大于0时显示0%。

示例：

| 题目 | 选项 | 总计 | 18岁及以下 | 19-25岁 | 26-30岁 | 31岁及以上 |
|---|---|---:|---:|---:|---:|---:|
| S1.请问您的性别是？ | 女 | 50.0% | 45.0% | 65.0% | 30.0% | 60.0% |
|  | 男 | 50.0% | 55.0% | 35.0% | 70.0% | 40.0% |
|  | 总计 | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% |
|  | 样本量 | 100 | 25 | 25 | 25 | 25 |

## 3. 量表题结构

满意度五分题常用顺序：

`非常满意 / 比较满意 / 一般 / 比较不满意 / 非常不满意 / TOP2 / 总计% / 均值 / 样本量`

如果原问卷方向相反，应按用户指定或已记录的阅读方向输出，并在使用说明中记录转换关系。

## 4. 矩阵题结构

### 矩阵单选题

- 每个矩阵行项目视为一道子题；
- 输出各选项分布及方案确定的 TOP2、均值、样本量；
- 如果进行交叉分析，每个交叉组按组内有效样本计算列百分比。

### 矩阵多选题

- 每个矩阵行项目与各多选项形成明细结果；
- 默认以该项目的有效答题人数为分母计算选择率；
- 总体列与交叉组列分别使用各自有效答题人数；
- 各选项选择率之和允许超过 100%；
- 每个矩阵项目底部增加“总计”行和“样本量”行；“总计”为该列各选项选择率之和；
- 项目及选项的展现顺序遵守原问卷或确认后的逻辑顺序。

## 5. 格式

- 默认采用统一、可编辑的表格格式；用户指定 iResearch 样式且 `iresearch-excel-format` 可用时才调用；
- 字体：微软雅黑；
- 表头：清晰区分表头与数据；选择 iResearch 样式时用其绿色底、白字、加粗；
- 正文：10pt、深灰字；
- 百分比：`0.0%`；
- 均值：`0.00`；
- 原始频数：整数；加权频数按所需精度保留小数；
- 隐藏网格线；
- 冻结表头和必要的前两列；
- 不使用合并单元格承载数据。
- 普通选项行使用白色与 `F2F2F2` 斑马纹；
- `总计`、`总计%`、`TOP2`、`均值`等统计摘要行统一使用 `D9D9D9` 底色；
- `样本量`行统一使用 `D1E8B2` 底色；
- 统计摘要行的固定底色优先于普通斑马纹，不因所在行奇偶变化。

## 6. 质检 Sheet

至少包括：

- 原始样本数；
- 有效样本数；
- 重复样本数；
- 关键变量缺失；
- 越界值；
- 跳题异常；
- 多选题互斥冲突；
- 合并题重叠/遗漏；
- 配额分布；
- 小样本提示。

按本次采用的方法补充逐题样本筛选、权重检查、配对匹配、重叠样本处置和已知答案复算结果。检查内容分别落在计算、数据处理、单表与跨表四类，无需重复生成四份报告。

## 7. 结果索引与解读

主Skill规定的结果索引字段保持；加权时“分子”和“有效Base”分别记录加权分子与权重和，另加“实际样本量”和“分母类型”。均值的分子是数值加权和；复杂指标写入计算说明和明细位置。索引与题目块使用同一结果ID。

专项检验表列明比较双方、各自样本量、指标值、差值与方向、区间、检验名称、原始p值及适用的校正p值；表注写明置信水平、配对或独立关系及校正范围。未满足计算条件的单元格说明具体缺项，其余结果继续交付。

“数据分析结论”按研究问题组织：**发现→关键差值与人群→可能解释及其依据→对当前决策的含义**，附结果ID或单元格位置。材料只能说明差异时，明确下一步验证的解释。长串赋值和计算过程留在方法说明或脚本；正文只保留改变判断的条件。同一限制集中说明一次，保留事实、推理或行动信息，删除重复免责和自我辩解。
