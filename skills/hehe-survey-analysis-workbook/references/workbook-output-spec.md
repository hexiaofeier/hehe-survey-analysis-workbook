# 基础分析工作簿输出规范

按清洗、统计两个阶段分别组织交付。只清洗不生成统计结果索引或逐题统计表；统计按用户已确认的纳入范围进行。

## 0. 文件形式与阶段交付

- **样本检查工作簿（`.xlsx`）**：无论输入为 Excel、CSV 还是 SAV，默认交付可编辑的 Excel 审阅文件。全量表保留全部原始记录及字段值，追加“明确无效/证据不足/合格”质量判断、正常/异常标记、异常说明与证据、Agent纳入建议、用户纳入决定及来源；未确认的决定写“待决定”。质量标签不自动决定纳入范围。异常说明、质量摘要、规则、结构对比、分析条件与版本等内容按[样本清洗与质量检查](sample-cleaning-and-quality.md)第9节组织，可合并相关内容，不按固定 sheet 数验收。
- **字段字典**：输入含变量标签、值标签或多选集合定义时，在样本检查工作簿中保留字段字典，记录原变量名、对应题号、变量/题目标签、选项编码与值标签，以及已有的多选集合及其成员字段。保留来源定义，不用展示名称替换原变量名。
- **统计分析工作簿（`.xlsx`）**：统计阶段另交，按下述结构保留完整逐题明细和本次确认的分析。已单独交付样本检查工作簿时，统计工作簿只承接质量摘要、确认的纳入范围、权重与版本记录，并提供指向样本检查文件的相对链接；不再复制原始数据和大量重复的质量处理明细。
- **分析简报（`.md`＋`.html`）**：完整分析默认提供，两种格式内容一致，概括主要发现、重要人群差异与业务含义，并链接统计工作簿。HTML 为带左侧目录的下拉阅读版，自带生成脚本与模板；内容、制作和检查见 [HTML简报交付](html-brief.md)。只清洗、仅跑数或局部查题不自动扩成交付简报。
- **可复跑脚本与运行说明**：交付实际使用的 `.py` 脚本；实际使用 R 时可交 `.R`。另交 `.md` 运行说明，列明输入输出文件、所需依赖及版本、运行命令，以及纳入决定和权重的读取方式；依赖清单可直接写在说明内。
- 保留输入原文件，不默认回写 SAV。用户指定其他交付格式时按其要求；CSV 仅作按需提供的便携数据副本，不替代默认的 Excel 审阅文件。

## 1. 通用结构

- 第一张 sheet 为“使用说明”，提供可点击的工作簿目录，直接跳转至分析方案、数据分析结论及各结果模块；
- 第二张为“分析方案”，说明研究问题、分组理由、指标及计算口径；
- 结果索引保存为过程文件中的独立 JSONL 或 CSV，不作为交付 Excel 的工作表，也不以隐藏表保留；
- 完整分析必须有“数据分析结论” sheet；仅跑数或导表时按任务需要设置；
- 中间 sheets 按问卷模块和原题号顺序排列，保留完整逐题明细；
- 末尾放数据质检、专项分析、开放题原文或合并检查；
- 工作簿不包含图表。

## 2. 基础表结构

常规交叉表使用宽表：

`题目 / 选项 / 总计 / 交叉组1 / 交叉组2 / …`

- 题目只在题目块第一行显示；
- 题目块之间使用上边框或空行区分；
- `总计`列表示全部有效样本的总体结果，各交叉组列表示各组内部结果；
- 完整分析在各模块的总体列右侧并列主要维度分组；列数较多时可在同模块分区，重复题目、选项和总计列，保持共同顺序；
- 分组列头明确写出维度与组别；不同题块改变分组时分别给出对应表头，冻结或打印重复标题不沿用上一组的含义；
- 常规单选交叉默认输出列百分比，每一结果列分别合计为 100%；
- 题目块底部增加“总计”行和“样本量”行；
- 单选题分母大于0时，“总计”行在总体列和各交叉组列均显示 100%；
- “样本量”行分别显示总体及各交叉组实际有效人数；
- 所有题目的有效回答人数统一命名为“样本量”，不得混用“答题人数”“Base”等其他行名；
- 多选题和矩阵多选题也必须增加“总计”行；该行等于本列所有多选项选择率之和，因此允许超过 100%；
- 多选题和矩阵多选题的“样本量”仍为回答该题的人数，不是选择次数；
- 题目块内部顺序遵守题目排序规则。
- 原问卷标记为“选项固定”的题目，严格按原问卷选项顺序呈现。

加权表以权重和计算比例与均值，“样本量”行仍显示实际有效人数，另增“权重和”行；需要评价权重离散程度时附“Kish有效样本量（权重近似）”。原始频数为整数，加权频数可保留小数，二者使用不同列名。分母为0的结果显示“—”，真实0次选择且分母大于0时显示0%。

两个分类变量的对照表，按研究问题确定行列及百分比方向；表头或表注说明各自代表的状态、选择和分母，保留各行或列的样本量，人数与百分比分开标明。

示例：

| 题目 | 选项 | 总计 | 18岁及以下 | 19-25岁 | 26-30岁 | 31岁及以上 |
|---|---|---:|---:|---:|---:|---:|
| S1.请问您的性别是？ | 女 | 50.0% | 45.0% | 65.0% | 30.0% | 60.0% |
|  | 男 | 50.0% | 55.0% | 35.0% | 70.0% | 40.0% |
|  | 总计 | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% |
|  | 样本量 | 100 | 25 | 25 | 25 | 25 |

## 3. 量表题结构

满意度五分题常用顺序：

`非常满意 / 比较满意 / 一般 / 比较不满意 / 非常不满意 / TOP2 / 总计% / 均值 / 样本量`

如果原问卷方向相反，应按用户指定或已记录的阅读方向输出，并在使用说明中记录转换关系。

## 4. 矩阵题结构

### 矩阵单选题

- 每个矩阵行项目视为一道子题；
- 输出各选项分布及方案确定的 TOP2、均值、样本量；
- 如果进行交叉分析，每个交叉组按组内有效样本计算列百分比。

### 矩阵多选题

- 每个矩阵行项目与各多选项形成明细结果；
- 默认以该项目的有效答题人数为分母计算选择率；
- 总体列与交叉组列分别使用各自有效答题人数；
- 各选项选择率之和允许超过 100%；
- 每个矩阵项目底部增加“总计”行和“样本量”行；“总计”为该列各选项选择率之和；
- 项目及选项的展现顺序遵守原问卷或确认后的逻辑顺序。

## 5. 格式

- 默认采用统一、可编辑的表格格式；
- 字体：微软雅黑；
- 表头：默认 `264863` 深蓝底、白字、加粗；用户明确指定其他样式时沿用该样式；
- 正文：10pt、深灰字；
- 百分比：`0.0%`；
- 均值：`0.00`；
- 原始频数：整数；加权频数按所需精度保留小数；
- 隐藏网格线；
- 冻结表头和必要的前两列；
- 不使用合并单元格承载数据。
- 普通选项、统计摘要和“样本量”行统一白底；不使用斑马纹或摘要、样本量色块；
- 题目块内每个单元格使用 `BFBFBF` 细灰色实线边框，包括后续行留空的题目列；题块之间的空白分隔行不加框；
- 题目和“选项／指标”左对齐，比例、均值和样本数等数值右对齐，长题干换行并顶端对齐；
- `总计`、`总计%`、`TOP2`及`均值`等汇总行的标签和结果加粗；“样本量”以行或列呈现时，其标签和结果均加粗，保持白底及相同边框；
- 表头和行高适配实际文字，不裁切选项、组名或数值；工作簿中的使用说明、分析方案及质量标记页按各自用途排版，不改变质量标签含义。

## 6. 质量摘要与统计质检

质量摘要至少包括下列项目。已单独交付样本检查工作簿时引用其确认记录，只保留汇总和文件链接；本轮统计新增的检查与处理结果仍需记录。

- 原始样本数；
- 全量标记记录数、明确无效/证据不足/合格人数；
- 用户确认纳入/未纳入/待决定人数及决定依据；
- 有效样本数；
- 重复样本数；
- 关键变量缺失；
- 越界值；
- 跳题异常；
- 多选题互斥冲突；
- 合并题重叠/遗漏；
- 配额分布；
- 小样本提示。

按本次采用的方法补充逐题样本筛选、权重检查、配对匹配、重叠样本处置和已知答案复算结果。检查内容分别落在计算、数据处理、单表与跨表四类，无需重复生成四份报告。

保存后重新读取最终工作簿，核对实际显示值、表头及目录和结论链接，确认数值与后台结果一致、链接指向实际存在的位置。

## 7. 后台结果索引与解读

主Skill规定的结果索引字段保持，独立保存在过程文件中，不进入交付 Excel。加权时“分子”和“有效Base”分别记录加权分子与权重和，另加“实际样本量”和“分母类型”。均值的分子是数值加权和；复杂指标写入计算说明和明细位置。索引保留结果ID及实际 sheet／单元格位置，供脚本复核和下游取数；交付工作簿的目录及结论直接链接对应结果，移出索引时同步清除或改正指向索引的旧链接。

专项检验表列明比较双方、各自样本量、指标值、差值与方向、区间、检验名称、原始p值及适用的校正p值；表注写明置信水平、配对或独立关系及校正范围。未满足计算条件的单元格说明具体缺项，其余结果继续交付。

“数据分析结论”先给总体发现，再按研究问题组织：**发现→关键差值与人群→追查结果及解释→对当前决策的含义与建议取舍**，附结果ID，并设置可点击链接，跳转到支持结论的结果 sheet 或单元格。追查过程按统计口径参考第5节执行；新增分层结果归入相应原模块或专题，保留其分母与条件。材料只能说明差异时，明确下一步验证的解释。长串赋值和计算过程留在方法说明或脚本；正文只保留改变判断的条件。同一限制集中说明一次，保留事实、推理或行动信息，删除重复免责和自我辩解。
