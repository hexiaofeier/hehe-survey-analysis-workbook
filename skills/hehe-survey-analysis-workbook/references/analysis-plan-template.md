# 分析方案记录模板

按以下格式记录已知口径；只有会改变结果的事项缺失或冲突时，集中请用户确认，不重复询问已说明的要求。

本次用法：只清洗／只统计／清洗后统计。只清洗填写第一节中的样本与处理口径和第七节交付，其余统计章节跳过；已有处理结果时沿用其版本与决定。

## 一、数据与问卷

- 数据文件：
- 数据格式：
- 有效样本定义：
- 用户已确认的纳入名单或规则、决定来源及版本（未确认则先交全量标记和异常说明，集中确认）：
- 问卷或题目字典：
- 原问卷是否包含题型及选项固定/随机标记：
- 权重/配额变量：
- 缺失值与跳题处理：
- 样本处理状态与各项分析可用范围（已有交接 ID 时记录）：
- 质量检查规则、阈值依据、三类质量判断、纳入建议、用户待决定事项及版本（本次清洗时填写）：

权重存在时补充来源与用途、字段和版本、零值／缺失处理、分层／整群或重复权重信息。每题记录“符合显示条件人数→实际有效回答人数”的筛选过程；多选全空与全0的含义从平台编码或问卷逻辑确定。

## 二、分析重点与工作表安排

先填写下面的关键维度与指标，再安排工作表。

### 需要回答的问题与关键交叉维度

| 需要支持的研究判断 | 交叉维度及题号/实际字段 | 选择理由 | 分组定义 | 重点比较的题目/指标 | 适用人群与分母 |
|---|---|---|---|---|---|
| | | | | | |

用户已指定的维度优先沿用；其余根据使用条件、行为、需求和购买条件等主动提出。“选择理由”栏说明维度测量什么、预期影响及对应的产品或服务选择，并标明主要或专题用途；“分组定义”栏记录原类别、合并或探索性划分的依据。维度数量由问题与数据决定，不以固定数量凑表。全样本总体结果按范围内全部题目保留，重点交叉说明对应问题。

### 派生指标（需要时填写）

| 指标或分组名称 | 来源题号/字段 | 计算或分组规则 | 跳题/缺失处理 | 适用人群与分母 | 分析用途 |
|---|---|---|---|---|---|
| | | | | | |

原字段保留，派生字段另列；不需要组合或重分组时跳过本表。

涉及类型核验、转入转出或多入口合并时，先在后台定义文件写清入口字段、确认类型、归类条件、调整前后人数和有效回答范围，再计算组合指标。对应方法见[统计口径与方法选择](statistical-methods.md)第0节。

完整解读同时安排总体发现和重点追查：总体要说明哪些行为或需求；哪些人群差异值得利用现有字段继续分层或跨题比较；这些结果将支持哪些建议及取舍。局部查题不扩成完整分析，追查计划随实际发现和可用字段补充，不机械铺开全部交叉。
