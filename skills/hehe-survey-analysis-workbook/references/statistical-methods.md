# 统计口径与方法选择

统计分析先读第0—2节，确定关键维度、指标及逐题分母；使用权重读取第3节；比较、检验和解读读取第4—5节。专项题组另见[专项分析计算参考](special-analysis-methods.md)。

## 0. 全样本分析、关键交叉维度与派生指标

完整分析先安排本轮用户确认纳入对象的逐题总体结果，再围绕研究问题确定重要人群维度。Agent根据研究目标、业务背景、最终问卷和实际字段提出维度，说明选择理由、分组定义和重点比较内容；用户已指定的维度优先沿用。

选择维度时按以下顺序思考：

1. **找可能改变需求或行为的条件。** 检查使用环境与资源、实际行为与使用阶段、需求与问题经历、购买条件等变量。每个候选维度说明实际测量什么、预计影响哪些需求或行为，以及比较结果可能改变哪项产品或服务选择。人口属性在能解释本次问题时纳入比较，原问卷背景题仍保留基础结果。
2. **确定比较要回答的具体问题。** 例如充电服务研究中，附近有无充电设施可能对应不同的公共充电依赖和服务诉求，可比较排队、费用、满意度及改进需求。具体维度以实际问卷为准，“附近有公共桩”和“有家庭专用充电设施”分别识别。
3. **落实字段与分组。** 按实际题干、选项和编码核对字段；写明组别边界与未知/未答处理，核对各组能否回答目标题、是否存在重叠。先保留有业务含义的原类别；合并时按共同的使用条件、需求或服务安排说明依据，保留原码对应。探索新的组合或连续变量切点时，记录依据并比较不同划分是否改变解释。同一题的不同人群按相同测量口径比较，不能把未展示者算作未选择者。
4. **列出主比较并检查可用人数。** 先确定重点题目与指标，再看结果；有必要时做进一步分层，核对总体差异是否集中于某类使用条件。小组可保留人数和描述结果，是否检验按设计与精度判断，不设统一的最低人数。

将维度与理由记入现有分析方案，不要求用户自行列全，也不为每个常规分组重复确认。材料没有支持相关比较的变量时，说明具体缺口并完成能做的总体结果。全部变量两两交叉仅在用户要求或有明确用途时执行；用户只查某题、某组或总体时沿用其范围。

对核心决策重要、能贯穿多个关键模块且提供不同解释的候选，选为主要维度；只解释局部问题或用于核查其他解释的，选为专题维度。名称或含义相近的变量先区分经历范围、实际行为、偏好或计划等测量内容，必要时查看共同分布，再确定主次，按研究需要分别保留或联合分析。完整分析先逐模块核对画像、行为、需求和评价题的适用范围，主要维度用于所有可分析且口径相容的题目；进一步分层和组合条件按研究问题选择。覆盖记录并入现有题目映射：`模块/题号｜维度｜适用人群｜已输出或未交叉原因｜结果位置`。分支题按各组真实有效回答计算；分组定义题自身、未编码原文、缺失字段或口径不相容的题明确处理原因，不把这些题补成0，也不将自我定义的差异解释为发现。局部任务保持原范围。

探索中发现新的重要维度或需要调整分组时，记录新依据，保留原方案与结果，补算相关题目；确定主要或专题用途后，同步更新覆盖安排及解读。

研究问题需要组合答案或重分组时，建立派生指标：记录来源字段、计算/分组规则、适用人群、缺失与跳题处理、分母和用途；保留原字段，新增派生字段。例如“买过且经常使用”取同一对象、同一品类下两个已知状态的交集，不能把未知或未展示直接补为否；区间变量的切点和标签说明业务依据。会改变研究含义但无法从材料确定的口径集中确认，其余明确部分继续。

多选题需要比较使用组合时，可按业务含义派生互斥组，例如“仅用某方式、该方式与其他方式并用、未用该方式”；写清各组包含的选项，核对组间互斥及对有效答题人群的覆盖，无法归组的未答或矛盾记录单列，保留原选项结果。

存在后续类型核验、品类转入转出或多入口合并时，计算前在后台记录对象对应关系：`来源入口及字段｜确认类型及字段｜归类条件｜转入/转出处理｜纳入对象及有效人数｜所需回答状态｜派生结果`。先逐类核对原入口、调整后类别和具体子型的人数，再计算购买、使用或评价的组合；同一品类从多个入口出现时按已确认分析单位取并集。原字段和用户纳入决定保持，归类记录放入现有定义文件，不另加用户阅读工作表。

## 1. 先确定谁回答了这道题

对每题、每个矩阵行和每个交叉组建立有效样本集合：用户确认的样本纳入范围→显示/跳题资格→题目实际有效回答。单次答卷按受访者ID识别重复提交，统计采用用户已确认的分析单位及重复记录选择；追踪或重复任务按ID＋波次/任务识别记录，保留有效重复测量。全量记录继续保留，记录各步人数与计算排除原因；纳入答卷不等于其每题每个值均有效。

| 数据情况 | 计算方式 |
|---|---|
| 结构性跳题、未展示 | 不进入该题分母 |
| 展示后未答、无效编码 | 单列缺失；按已定口径计算有效回答分母 |
| “不知道”“不适用”是实际选项 | 在分布中保留；均值、TOP2等指标分别说明是否排除及其分母 |
| 多选题某项0 | 仅在已确认有效作答且0表示未选时计为未选 |
| 多选题全空或全0 | 结合平台编码及路由判断未答或有效未选；空白不能直接全部补0 |
| 展示给不同人的动态选项 | 普通选择率按全题Base；若分析“看到该选项后的选择率”，改用该项曝光人数并标明不同口径 |

从题目字典补齐零频选项。分组变量缺失时，保留总体结果，并单列未分组人数；仅互斥且穷尽的分组才能用组内人数和分子还原总体。多选分组允许同一人出现在多列，列样本量不可直接相加。

## 2. 基础指标

| 题型/指标 | 计算与呈现 |
|---|---|
| 单选比例 | 选该项人数／本题有效人数；同一列完整分布合计100% |
| 多选选择率 | 有效受访者中选该项人数／本题有效人数；每人对同一项最多计一次；总计可超过100% |
| 按选择次数的多选占比 | 该项选择次数／全部项选择次数；与按人数的选择率分开命名 |
| 矩阵 | 每行项目独立计算有效人数，再算分布、均值或选择率 |
| 量表 | 先确认编码方向与分值映射；TOP2取语义最高两档；均值使用有效数值回答；必要时给分布、中位数或分位数解释分化 |
| 排序 | 首选率以有效排序人数为分母；平均名次注明仅在排入该项的人中计算；未排入保持缺失。综合得分须写明各名次分值和未入选处理 |
| 开放题编码 | 保留ID—原话—主题对应；可多主题，频率按去重提及人数／有效开放回答人数；词频另表，不能替代人数比例 |

例：3名有效受访者分别选AB、A、B，A和B选择率各为2/3，总计4/3；若有第4名结构性跳题者，分母仍为3。计算保存未四舍五入值，展示时统一精度。

## 3. 加权

沿用已确认权重及版本；先核对权重适用对象、缺失、非有限值、负值、零值及极端值。发现异常说明影响并确定处置；已验收权重的重新校准或截尾需形成明确新版本。没有权重时正常输出未加权结果。

在同一题、同一组的有效集合V中：

- 加权比例：`Σ(wᵢ × 是否选中) / Σwᵢ`。
- 加权均值：`Σ(wᵢ × xᵢ) / Σwᵢ`。
- 实际“样本量”：V中的真实人数；“权重和”：`Σwᵢ`；二者分别呈现。
- Kish有效样本量：`(Σwᵢ)² / Σ(wᵢ²)`，仅衡量权重不均的近似影响；完整抽样设计的误差还受分层、整群等因素影响。

零权重样本按既定规则留在实际人数中，对加权分子、分母贡献为0；全组权重和为0时结果为空并说明原因。缺失权重的样本不能被静默改成1，适用样本范围变化要同步写入结果。

例：3人回答1、0、1，权重1、2、3，加权比例为4/6，实际人数3、权重和6、Kish有效样本量36/14。权重统一乘10后，比例、均值与Kish有效样本量不变。

加权区间与检验匹配抽样设计：有分层、PSU或重复权重时采用设计相容的调查估计；R `survey`等是可选实现。普通校准样本记录目标总体边际与校准方法，解释加权前后差别。不要把权重和当作实际独立样本数送入普通检验，Kish近似也不能自动替代完整设计。仅有配额或便利样本时，可继续比较样本内差异；若估计区间，说明其模型假设与适用范围。

## 4. 按问题选检验

先确定要比较的量、组间关系与测量尺度。下表为未加权或简单随机样本的常用途径；复杂权重、整群、重复测量要采用对应的设计或模型。

| 问题与样本关系 | 方法选择 | 核心结果 |
|---|---|---|
| 两独立组的均值差 | 通常用Welch t；有充分等方差依据时用合并方差t | 各组n、均值、均值差及区间；需要时附标准化差异 |
| 同一人前后/两产品评分 | 按ID对齐后，对差值做配对t；秩问题可用满足条件的Wilcoxon | 配对数、变化方向、平均变化及区间 |
| 三组及以上独立均值 | Welch ANOVA及匹配的事后比较；等方差模型用ANOVA及相应比较 | 总体检验与具体组间差异分开 |
| 两独立组比例 | 两比例检验；稀疏2×2表可用Fisher精确检验 | 各组人数与比例、百分点差、适当区间 |
| 同一人前后是否选择 | McNemar；稀少不一致对可用精确二项版本 | 0→1与1→0人数、净变化、配对检验 |
| 分类变量关联 | 列联表卡方；稀疏表用适合的精确或模拟方法 | 频数、预期频数、关联强度及主要差异 |
| 有序或分布差异 | Mann–Whitney、Kruskal–Wallis等秩方法；按问题解释秩/分布 | 分布、相应效应量；不自动称为中位数检验 |
| 数值关系 | 线性关系用Pearson，单调秩关系用Spearman；解释变量关系需按目标选择回归 | 方向、强度、区间与适用样本 |

多选题的选项是同一人的多项回答：独立人群间可逐项作为二元变量比较；同一人对两个选项的偏好比较采用配对方法。随机化实验按分配单位分析；普通横截面关联依研究设计解释。

比较组与包含它的总体存在重叠。可展示描述性差值；做检验时改成组与其余样本的独立比较，或用处理协方差/聚类的模型，并把实际检验对象写清。品牌用户交叉、同户多人、追踪样本也先识别这种依赖关系。

查看分布、异常值、样本失衡及模型残差，选择与研究问题相符的方法；不要仅按一次正态性检验的p值自动换检验。小组仍可呈现人数、分布和差异，是否推断取决于设计与估计精度。

同一研究问题的一组比较预先确定校正范围。需要控制任一误报可用Holm；探索大量候选可用适合依赖结构的FDR方法，注明探索性质。保留原始p值、校正p值、比较数量和实际方法；避免先筛显著项再校正。计算用完整精度，显示不把小p值写成0。

## 5. 差异怎样变成有用结论

完整分析先概括总体发现，再围绕研究问题综合多道题。总体发现说明本轮对象主要呈现什么行为、需求和使用或购买条件，选用与研究目标相关的总体指标及各自分母；随后进入重点人群比较。已有逐题总体表不能代替这段总体判断。

按以下步骤形成解读，用户只要求某题或某组时按其范围执行：

1. 汇集与该问题有关的总体、关键人群和派生指标结果，保留结果ID或单元格位置。
2. 核对对象、品类、时间和分母是否一致；不同对象的结果可以并列说明，但不能直接拼成同一人群的转化链。
3. 比较一致与矛盾。例如购买覆盖高、经常使用低，说明需要进一步区分使用阶段、替代方案和具体问题；总体满意度高与某项问题发生率高可以同时存在，应分别解释其含义。
4. 依据业务含义、涉及人数及差异幅度选择值得追查的主题，先说明待解释的差异及可能的构成因素，再用相关现有字段实际分析：比较相同使用条件或人群中的差异，或把评价与行为、用途、问题经历配对。差异涉及合并类别或可拆分的汇总指标时，拆回原组成项，定位差异主要来自哪些组成项。对照总体结果，说明原判断保持、缩小、反转或需要重新解释。追查限于会影响本次判断且数据能回答的问题，不要求每题增加多层交叉；问卷没有测量的原因写成待验证解释，不能补成已发现事实。
5. 提出当前数据支持的判断与优先行动，说明适用人群及依据；数据可比较多个选项时把差异、涉及人数与实际意义放在一起，不无依据地合成一个分数。

完整解读沿同一分组串联问卷已测量的画像、目标、行为、困难、需求和购买条件，形成有事实依据的人群小结；同时总结共性与差异，说明哪些产品内容或服务可以共用，哪些需要按人群配置。各项比例保留自己的适用分母，人群小结写入原结论页和简报。

例如分析教育硬件的品类机会，可并列购买、经常使用和满意度结果，再定位持续使用落差集中在哪些家庭或使用阶段；每项采用自己的有效回答范围，按问题需要计算“买过且经常用”的共同人群。该例说明分析动作，不预设任何品类的结果。

题目测量的状态含义不同，应先对照再解释。例如“未列为常用”与“低频使用”需要同一人的使用频率题核对；城市差异可在相同收入或相同使用条件中进一步比较；已有问题经历或用途题可用于定位差异，分析完成后再提出新增研究需求。

建议写明具体对象与条件、支持该判断的结果及优先理由，并落实到产品、服务、目标人群或后续研究的具体动作。优先次序结合问题覆盖、影响程度、相关行为及材料中已有的实施条件，说明为何先处理这一项；研究目标不需要排序时可以并列。将建议写入原“数据分析结论”和简报，不新增固定数量的分析sheet，也不由某个低分直接推定改进效果。

先讲对象、差多少和对决策的意义，再给检验支持。区分百分点差与相对变化，比例的区间和差值的区间分别标明。结果不显著时，根据区间说明仍可能存在多大差异；需要判断“足够接近”时设业务容忍范围并选择等效性分析。

例如，两类用户需求率为60%和40%，先解释20个百分点差异集中在哪些任务、对应什么产品取舍，再说明人数和区间。开放题可用于理解原因，报告其编码覆盖范围；原因尚待验证时明确验证动作。对不同时间或人群比较，检查整体差异是否来自样本构成变化。

按需用已定样本量评估最小可检出差异，或用区间判断精度；不把基于本次观察效应计算的“事后功效”当作新证据。
