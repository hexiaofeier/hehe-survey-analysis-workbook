# HTML简报交付

完整统计分析默认在 Excel 之外交付同内容的 Markdown 与 HTML 简报，便于阅读分析结果。只清洗、仅跑数或局部查题时不自动扩成完整简报；用户要求时按对应范围制作。直接使用本技能自带脚本和模板，不需要另装报告写作、分页或呈现 Skill。

## 内容

根据已核对的工作簿编写简报 Markdown：

- 开头交代研究对象、数据期间、用户确认的纳入范围、权重及影响解读的样本条件；
- 先给总体发现，概括与研究目标有关的主要行为、需求及购买或使用条件，再进入细分人群；
- 按研究问题组织主要发现，用完整段落说明比较对象、指标差值、可能解释及业务含义；标题直接陈述发现，不只复述题号；
- 重点差异结合已有字段的进一步分层或跨题结果解释，最后提出有依据的建议及取舍，具体方法见[统计口径与方法选择](statistical-methods.md)第5节；
- 关键比较写明各组样本量和适用分母，多选组重叠、重复记录或配对关系在影响判断的位置解释；
- 需要逐项比较时使用短表，逐题明细留在 Excel，不把结果索引或所有交叉组合搬入网页；
- 结尾列出实际交付的工作簿及证据位置，保留结论对应的结果ID或 sheet／单元格。只链接实际存在的附件。

简报与“数据分析结论”使用同一组核对后的结果。保留事实、推理及业务含义，合并重复提醒；新增解释必须区分数据已发现的现象与需要进一步验证的原因。已有合格简报可以直接转换，不必重写。

## 生成

制作端需要 Python 3.10及以上、`markdown` 和 `beautifulsoup4`；缺少时安装这两个包即可。阅读端仅需浏览器。

```text
python -m pip install markdown beautifulsoup4
python scripts/render_brief.py 简报.md 简报.html
```

命令在本技能目录执行；从其他目录调用时使用脚本的实际路径。脚本默认不覆盖已有输出；修改时另存版本，明确需要覆盖时加 `--force`。交付时保留 Markdown、HTML、实际使用的生成命令，以及相对链接所需的 Excel 附件；附件可留在原位置，脚本会按 HTML 输出位置换算链接。

HTML 使用随包 `assets/brief.html`：深蓝侧栏、青色强调、白底正文；二三级标题形成目录，桌面固定显示、窄屏可折叠，正文自然下拉。图片如需使用则由本地文件内嵌，样式与交互同文件保存，不加载网络字体或在线组件。打印隐藏导航，按 A4 自然分页并保留背景色；不设置翻页画布，不默认生成 PDF 或显示不存在的 PDF 下载入口。

## 验收

1. 对照 Markdown 与最终 HTML 的可见正文、表格和链接，内容及数字不丢失，简报数字能定位到工作簿结果。
2. 桌面实际打开，检查目录层级、重名标题锚点、点击定位及滚动高亮；在窄屏检查开关、阅读宽度和局部宽表滚动。
3. 检查离线打开及附件路径；HTML无外部样式或脚本依赖，所有目录锚点存在且唯一。
4. 查看打印预览或实际打印渲染：侧栏、目录按钮等操作控件隐藏，正文不截断，长表表头可重复。技术检查与内容审阅分别记录，不因文件生成成功就认定简报有效。
